# The Mystery Files

## The Stolen Exam Paper

The Mystery Files is a menu-driven Python detective game based on a fictional college investigation.

In Case, a sealed Calculus exam paper goes missing from a faculty office. The player investigates the case, examines evidence, interviews suspects, reconstructs the timeline, and finally identifies the person responsible.

## Features

* View case details
* View suspects and their statements
* Investigate the faculty office
* Collect and examine evidence
* Interview suspects
* Find contradictions in statements
* Reconstruct the timeline
* Review collected evidence
* Make a final accusation

## Requirements

* Python 3.14
